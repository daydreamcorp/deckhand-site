# deckhand-site (public)

This repository is public only because other systems must read it:

- `latest.json` — the desktop auto-updater's manifest (polled by every Deckhand Host)
- `notices.json` — notices the phone app shows
- release assets on the `latest` tag — the desktop installers and update binaries
- `privacy-policy.html` — a mirror of the Deckhand privacy policy

Its GitHub Pages address redirects to the website, https://getdeckhand.pages.dev,
whose source is private.
